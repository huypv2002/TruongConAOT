# Tool 2: Truong Con AOT - Driver Updater

Công cụ chuyên dụng kiểm tra, cập nhật và cài đặt Driver cho PC để bàn và Laptop.

---

## 🎯 Cách Sử Dụng
1. Sau khi cài xong Windows, mở ổ USB của bạn.
2. Vào thư mục `Tools/2-Driver-Tool/`.
3. Nhấp đúp chuột vào file **`Run-DriverUpdater.bat`**.

---

## ⚙️ Chế Độ Hoạt Động
- **Chế độ Offline**: Nếu bạn có tải sẵn bộ công cụ **Snappy Driver Installer (SDI)**, hãy chép thư mục `SDI` hoặc `Drivers` vào USB. Tool sẽ tự động nhận diện và cài đặt driver hoàn toàn không cần mạng.
- **Chế độ Online**: Nếu không có SDI offline, tool sẽ tự động kết nối API của **Microsoft Windows Update** để tải đúng các gói driver chuẩn xác cho CPU, GPU, Chipset, Audio và Wifi.
