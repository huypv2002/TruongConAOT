# Tool 3: Truong Con AOT - Application & Dev Setup

Công cụ tự động hóa cài đặt bộ phần mềm, công cụ lập trình, bộ Office 2024 LTSC, trọn bộ Visual C++ Runtimes (AIO 2005 - 2022) và tinh chỉnh tối ưu hệ thống mang thương hiệu Truong Con AOT.

---

## 🎯 Cách Sử Dụng
1. Đảm bảo máy tính đã có kết nối mạng (Wifi hoặc cáp LAN).
2. Mở ổ USB của bạn -> Vào thư mục `Tools/3-App-Tool/`.
3. Nhấp đúp chuột vào file **`Run-AppInstaller.bat`**.

---

## ⚙️ Tùy Chỉnh Ứng Dụng
Mở file `apps.ini` để bật/tắt phần mềm bạn muốn cài đặt:
- Chuyển `true` để cài đặt.
- Chuyển `false` để bỏ qua.
- Hỗ trợ cả gói cài đặt offline trong thư mục `packages/`.
